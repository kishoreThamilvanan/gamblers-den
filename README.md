# Gambler's Den 🎰♠️

> Modern live casino gaming & poker training simulation built with Next.js, React 19, Tailwind CSS, and Web Audio synthesis.

## Features

- **♠️ Texas Hold'em NLHE ($1/$2 & $1/$3)**: Full live casino simulation supporting 2-Max (Heads-Up), 6-Max (Short-Handed), and 9-Max (Full Ring) tables.
- **🎯 3 Skill Tiers & Bot Personas**: Realistic AI opponents across *Friday Night Fish*, *Casino Regulars*, and *Vegas Sharks* featuring unique timing tells, aggression factors, and behavioral tendencies.
- **🧠 Proactive Real-Time AI Coach**: Live pot odds, minimum defense frequency (MDF), equity calculations, and spoiler-free hint modes.
- **🛡️ Biometric Auth & Hardened Pit Boss Admin**: Dual-layer owner console (`/admin` and `Cmd + Shift + A`) with Touch ID / Face ID WebAuthn passkeys, player telemetry, and ecosystem leak intelligence.
- **↺ Street-by-Street Hand Replayer**: Interactive replay controls, equity progression curves, and post-hand blunder ledger.

## Getting Started

First, install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Testing & Quality

```bash
# Run unit tests
npm test

# Production build
npm run build
```
