# FeltSense Product Backlog Protocol

The running product backlog for **FeltSense** is maintained in [`felt-sense/BACKLOG.md`](../../felt-sense/BACKLOG.md).

## Mandatory Rules for Backlog Management
1. **No Unapproved Implementation**: NEVER start implementing any item listed in `felt-sense/BACKLOG.md` unless the user explicitly asks to start working on that specific item.
2. **Design & Planning Gate**: When the user selects a backlog item to work on, first align on requirements, edge cases, and architecture (e.g., via interactive design questions / `/grill-me` and a step-by-step implementation plan) and receive explicit user approval before writing production code.
3. **Keep Backlog Updated**: When the user shares new feature ideas to save for later, append them cleanly to `felt-sense/BACKLOG.md` with status `Backlog (Not Started — Awaiting Design & Approval)`. When a backlog item is officially completed and verified, move it to the `Completed Milestones` section of `felt-sense/BACKLOG.md`.
